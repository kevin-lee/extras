## Bug Fixed

* Fix: [`extras-hedgehog-circe`] `NoSuchMethodError` on hedgehog `0.15.0` (`Syntax.====` gained `SourcePos` param) (#641)

  `RoundTripTester` in `extras-hedgehog-circe` `0.56.0` was compiled against hedgehog `0.13.1`. hedgehog `0.15.0` changed the signature of `====`, so `RoundTripTester` threw `NoSuchMethodError` at runtime with hedgehog `0.15.0`. `extras-hedgehog-circe` is now built against hedgehog `0.15.0`.
